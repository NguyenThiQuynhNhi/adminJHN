Customer Notification States
UI reference for Customer subscription events. Each example below shows the user-facing copy, action pattern and dismiss behavior — not backend implementation details.
Display rule: transient events can use a dismissible toast. Events that still require user action should also remain accessible from the notification bell / relevant page until resolved. Do not rely on a 5–7 second toast as the only surface for an unresolved action.
